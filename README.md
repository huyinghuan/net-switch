# NetSwitcher（网络一键切换器）

NetSwitcher 是一款面向 Windows 的轻量网络工具，用于在有线以太网和 Wi-Fi 之间快速切换默认上网出口，并保存、切换工作中常用的固定 IP 配置。

它适合同时连接公司内网、家庭网络、无线热点等多个网络的电脑。程序通过调整 Windows 网卡跃点数来选择优先出口，也可以在需要时禁用备用网卡，避免流量走错网络。

## 主要功能

- 一键切换有线以太网和 Wi-Fi 出口。
- 使用稳定的网卡 ID 保存选择，网卡重命名后仍可识别。
- 普通模式保留另一张网卡作为备用连接。
- 隔离模式会禁用另一张网卡，确保只使用指定出口。
- 切换前保存原始网卡状态和跃点数。
- 切换后检查 IP、网关、DNS 和 HTTPS 连通性。
- 新出口不可用时自动恢复切换前的网络配置。
- 支持恢复 Windows 自动跃点数。
- 支持启动时恢复上次使用的出口。
- 支持保存多个固定 IPv4 配置，包括子网掩码、可选网关、DNS 和静态路由。
- 固定 IP 配置绑定稳定的网卡 ID，可从主界面或托盘菜单快速应用。
- 应用固定 IP 前保存当前设置，失败时自动回滚，且不会修改出口跃点数。
- 提供独立的“恢复自动获取（DHCP）”按钮。
- 最小化到系统托盘，可直接从右键菜单切换网络。
- 提供操作详情、诊断信息复制、日志查看和日志清理。
- 支持手动检查 GitHub Release，并下载、校验和安装新版本。
- 限制程序只能运行一个实例。

## 系统要求

- Windows 10 或 Windows 11（x64）。
- 修改网卡和路由配置需要管理员权限，程序启动时会请求提升权限。

## 下载版本

构建后会在 `artifacts` 目录生成两种发布物：

### MSI 安装版

文件名：`NetSwitcher-Setup-版本号-x64.msi`

- 安装到 `Program Files\NetSwitcher`。
- 创建开始菜单快捷方式。
- 支持从 Windows“已安装的应用”中卸载。
- 支持覆盖安装和版本升级。
- 安装向导允许用户修改安装目录。
- 安装前必须阅读并接受个人及内部使用许可协议和免责声明。
- 安装完成后会显示明确的完成提示。
- 安装包体积较小。
- 目标电脑需要安装 [.NET 8 Desktop Runtime x64](https://dotnet.microsoft.com/download/dotnet/8.0)。安装程序会检测运行时，缺失时给出提示。

### 独立 EXE 版

文件名：`portable\NetSwitcher.exe`

- 已包含 .NET 运行时。
- 不需要安装，复制到 Windows x64 电脑即可运行。
- 适合放在 U 盘或直接发送给其他电脑使用。
- 文件体积会明显大于 MSI 安装包。

## 使用方法

1. 启动 NetSwitcher，并同意管理员权限请求。
2. 在左侧选择有线网卡，在右侧选择 Wi-Fi 网卡。
3. 点击对应卡片上的切换按钮。
4. 等待程序完成网络配置和联网验证。
5. 最小化后，右键系统托盘图标也可以直接切换。

默认情况下，程序会降低目标网卡的跃点数，并提高备用网卡的跃点数。这样可以优先使用目标出口，同时保留备用连接。

启用“切换时禁用另一张网卡”后，程序会进入隔离模式。该模式更彻底，但切换期间可能出现短暂断网。

如果不再需要程序管理网络优先级，可以点击“恢复系统默认”，重新启用所选网卡并恢复 Windows 自动跃点数。

### 固定 IP 配置

打开主界面的“IP 配置”页，点击“新增配置”，选择目标网卡并填写 IPv4 地址和子网掩码。默认网关、DNS 和静态路由均可留空；仅连接同一交换机或访问同网段设备时通常不需要默认网关。

保存后可在主界面点击“应用此配置”，也可以从托盘菜单快速应用标记为快捷项的配置。应用固定 IP 不会改变现有的有线/Wi-Fi 出口优先级。

不再使用固定 IP 时，先选中对应配置，再点击独立的“恢复自动获取（DHCP）”按钮。程序会将该网卡的 IP 和 DNS 恢复为自动获取。

## 软件更新

程序不会在后台自动检查更新。需要时可点击主界面底部的“检查更新”，或使用托盘菜单中的“检查软件更新”。

检查更新时，程序会读取 `huyinghuan/net-switch` 仓库的最新正式 GitHub Release。断网、连接超时、GitHub 限流、仓库无 Release 或发布文件不完整时都会显示明确提示，不会影响当前版本继续运行。

程序会自动识别当前运行方式：

- MSI 安装版下载对应 MSI，退出当前程序后通过 Windows Installer 覆盖升级，然后重新启动。
- 独立 EXE 下载对应的 Portable EXE，退出当前程序后安全替换原文件，然后重新启动。

更新包必须通过 GitHub Release 资源摘要或 `SHA256SUMS.txt` 中的 SHA-256 校验，否则不会安装。自动更新要求 Release 中同时包含与版本号匹配的 MSI、Portable EXE 和校验文件。

## 安全切换与自动恢复

每次切换会依次执行：

1. 保存相关网卡的启用状态、IPv4/IPv6 跃点数和自动跃点数设置。
2. 应用新的网络出口配置。
3. 等待目标网卡获得 IP 和默认网关。
4. 通过目标网卡检查网关、DNS 和 HTTPS 连通性。
5. 如果验证失败，自动恢复切换前的配置。

最近一次操作的执行结果可以通过主界面或托盘菜单中的“操作详情”查看。

## 配置与日志

配置文件保存在：

```text
%LOCALAPPDATA%\NetSwitcher\config.json
```

日志文件保存在程序 EXE 所在目录：

```text
NetSwitcher.log
```

单个日志文件最大约 5 MB，并保留最近 3 份历史日志。托盘菜单中可以打开日志所在文件夹或清空日志。

复制的诊断信息可能包含本机 IP 地址和网卡标识，分享前请确认接收方可信。

## 一键构建

开发电脑需要安装 .NET 8 或更高版本的 SDK。首次构建 MSI 时需要联网下载 WiX 构建组件。

双击项目根目录中的：

```text
build-msi.cmd
```

脚本会依次生成：

```text
artifacts\NetSwitcher-Setup-版本号-x64.msi
artifacts\portable\NetSwitcher.exe
```

发布新版本前，请修改 `NetSwitcher.csproj` 中的 `Version`。程序使用这个版本号判断是否存在更新。普通功能和问题修复递增补丁版本（每次增加 `0.0.1`）；只有较大的功能变更才递增次版本（增加 `0.1`）。

也可以在 PowerShell 中运行：

```powershell
.\build-msi.ps1
```

或者指定版本号：

```powershell
.\build-msi.ps1 -Version 1.2.1
```

## GitHub Actions 自动发布

仓库包含 `.github/workflows/release.yml`，支持以下两种运行方式：

- 在 GitHub Actions 页面手动运行：自动构建并上传工作流产物，但不创建 Release。
- 推送 `v*` 格式的 Git 标签：自动构建、生成 SHA-256 校验文件，并创建 GitHub Release。

发布前，需要先把 `NetSwitcher.csproj` 中的 `Version` 改为新版本，并提交代码。Git 标签中的版本号必须与项目版本完全一致。

例如发布 `1.2.1`：

```powershell
git tag v1.2.1
git push origin main
git push origin v1.2.1
```

Release 会包含：

```text
NetSwitcher-Setup-1.2.1-x64.msi
NetSwitcher-Portable-1.2.1-x64.exe
SHA256SUMS.txt
```
